# Аватарки и логотип

Картинки для профилей: Telegram, WhatsApp, Авито, Яндекс Бизнес, ВКонтакте.
Все 800×800, в цветах сайта — тот же тёмно-коричневый фон, та же янтарная
птица и тот же шрифт Playfair Display, что в заголовках.

| Файл | Что на нём | Куда лучше |
| --- | --- | --- |
| `avatar-ptica.png` | птица в круге | Telegram, WhatsApp — читается даже кружочком 40 px |
| `avatar-monogramma.png` | монограмма «СИ» | тоже мессенджеры, если хочется букв, а не картинки |
| `logo-podpis.png` | птица + «СтройИнвест» + «Москва и область» | Авито, Яндекс Бизнес, ВКонтакте — там картинку показывают целиком |

Скачать с телефона: откройте
`https://stroyinvest-mo.ru/assets/brand/avatar-ptica.png`
(или другое имя файла) и подержите палец на картинке → «Сохранить в фото».

Мессенджеры обрезают аватарку в круг, поэтому всё важное собрано внутри
круга, а по краям оставлен запас. Подпись «Москва и область» есть только
в третьем файле — в кружке она всё равно превратилась бы в кашу.

## Если понадобится переделать

Картинки собраны из HTML-шаблонов в папке `tools/`:
`avatar-ptica.html`, `avatar-monogramma.html`, `avatar-podpis.html`.
Поменяйте в шаблоне цвет или текст и снимите скриншот 800×800 —
например, так (в среде, где есть Chromium):

```
chrome --headless --window-size=800,800 \
  --screenshot=avatar.png file://путь/к/avatar-ptica.html
```

Цвета в шаблонах прописаны числами намеренно: файл должен рисоваться
сам по себе, без `tokens.css`. Если меняете палитру сайта — поменяйте
и здесь, значения те же (`#2E2622` фон, `#F0A62E` птица, `#F2C67C` текст).
