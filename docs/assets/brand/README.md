# Аватарки и логотип

Картинки для профилей: Telegram, WhatsApp, Авито, Яндекс Бизнес, ВКонтакте.
Все 800×800. Знак — та же капля, что стоит иконкой во вкладке браузера
(`docs/favicon.svg`), только крупно; шрифт названия — Playfair Display,
тот же, что в заголовках сайта.

| Файл | Что на нём | Куда лучше |
| --- | --- | --- |
| `avatar-kaplya.png` | капля на тёплом коричневом фоне сайта | Telegram, WhatsApp — читается даже кружочком 40 px |
| `avatar-kaplya-sinyaya.png` | та же капля в цветах иконки вкладки | если хочется точного совпадения с favicon |
| `avatar-monogramma.png` | монограмма «СИ» | тоже мессенджеры, если хочется букв, а не знака |
| `logo-podpis.png` | капля + «СтройИнвест» + «Москва и область» | Авито, Яндекс Бизнес, ВКонтакте — там картинку показывают целиком |

Скачать с телефона: откройте
`https://stroyinvest-mo.ru/assets/brand/avatar-kaplya.png`
(или другое имя файла) и подержите палец на картинке → «Сохранить в фото».

Мессенджеры обрезают аватарку в круг, поэтому всё важное собрано внутри
круга, а по краям оставлен запас. Название есть только в `logo-podpis.png`:
в маленьком кружке оно всё равно превратилось бы в кашу.

## Один знак везде

12 сентября иконку вкладки (`docs/favicon.svg`) и иконку для телефонов
(`docs/apple-touch-icon.png`) перекрасили из старого тёмно-синего в цвета
сайта: фон `#2E2622`, капля `#F0A62E`, линии воды `#F2C67C`. Теперь вкладка
браузера, аватарка и логотип — один знак в одном цвете.

Линии воды остались только в иконках: в квадратике 16×16 они не дают капле
читаться как огонёк. На аватарках и в логотипе их нет — там знак крупный
и в подсказках не нуждается.

`avatar-kaplya-sinyaya.png` оставлен как второй вариант цвета — просто
если тёмно-синий нравится больше. С иконкой вкладки он больше не совпадает.

## Если понадобится переделать

Картинки собраны из HTML-шаблонов в папке `tools/`:
`avatar-kaplya.html`, `avatar-kaplya-sinyaya.html`, `avatar-monogramma.html`,
`avatar-podpis.html`. Поменяйте в шаблоне цвет или текст и снимите
скриншот 800×800 — например, так (в среде, где есть Chromium):

```
chrome --headless --window-size=800,800 \
  --screenshot=avatar.png file://путь/к/avatar-kaplya.html
```

Цвета в шаблонах прописаны числами намеренно: файл должен рисоваться
сам по себе, без `tokens.css`. Меняете палитру сайта — поменяйте и здесь
(`#2E2622` фон, `#F0A62E` капля, `#F2C67C` линии воды и текст).
