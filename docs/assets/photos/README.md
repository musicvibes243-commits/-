именами**. Если файла нет — снимок просто не показывается, сайт не ломается.
Если нет ни одного файла — весь раздел «Наши работы» скрывается.

## Как загрузить через сайт GitHub, без программ

1. Откройте репозиторий → папку `docs/assets/photos`.
2. Кнопка **Add file** → **Upload files**.
3. Перетащите фотографии в окно браузера.
4. Важно: файл должен называться ровно так, как в таблице выше
   (переименуйте на компьютере до загрузки).
5. Внизу нажмите **Commit changes**.

Через минуту сайт обновится сам, галерея появится.

## Требования к фото

- Формат **.jpg**, вертикальные кадры смотрятся лучше (обрезаются в 4:5).
- Размер файла — до 500 КБ на фото. Снимок с телефона весит 3–5 МБ, его стоит
  сжать (например, на squoosh.app), иначе сайт будет долго открываться
  с мобильного интернета.
- Только ваши собственные снимки. Чужие фото из интернета — это и претензии
  по авторским правам, и потеря доверия: клиенты узнают типовые картинки.

## Добавить больше фотографий

Откройте `docs/index.html`, найдите раздел `<!-- РАБОТЫ -->` и скопируйте
любой блок `<li class="shot">…</li>`, поменяв в нём имя файла, `alt`
(описание для незрячих и поисковиков) и подпись.
