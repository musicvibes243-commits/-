# АкваГрунт — сайт монтажника (кессоны, септики, дренаж)

Статический сайт: обычные файлы, которые браузер показывает как есть.
Ни базы данных, ни сервера, ни движка — значит, его нельзя «сломать обновлением»
и почти невозможно взломать. Работает и бесплатно живёт на GitHub Pages.

Посмотреть, не публикуя: откройте `index.html` двойным кликом.

## Что где лежит

```
docs/                     ← это и есть сайт
  index.html              главная страница: весь текст, стили и скрипты
  privacy.html            политика конфиденциальности (шаблон, надо заполнить)
  404.html                страница «такой страницы нет»
  favicon.svg             иконка во вкладке браузера
  og.png                  картинка ссылки в WhatsApp, Telegram, ВК
  apple-touch-icon.png    иконка при добавлении на экран iPhone
  robots.txt, sitemap.xml подсказки поисковикам
  assets/tokens.css       ЦВЕТА всего сайта — одно место на все страницы
  assets/fonts.css        подключение шрифтов
  assets/fonts/           сами шрифты (лежат рядом, Google не нужен)
tools/
  telegram-relay.js       приём заявок в Telegram (инструкция внутри файла)
  og-template.html        макет картинки og.png
  make-images.mjs         пересборка og.png и иконки
```

## Шаг 1. Опубликовать сайт (10 минут, бесплатно)

1. Откройте репозиторий на GitHub → вкладка **Settings** (шестерёнка сверху).
2. Слева в меню — **Pages**.
3. В блоке *Build and deployment*:
   - **Source**: `Deploy from a branch`
   - **Branch**: `claude/laughing-bardeen-64ejnt`, папка — **`/docs`**
   - нажмите **Save**.
4. Подождите 1–2 минуты и обновите страницу — вверху появится адрес сайта:
   `https://musicvibes243-commits.github.io/-/`

Готово, сайт в интернете. Каждый следующий push в эту ветку обновляет его сам.

> **Адрес некрасивый?** Репозиторий сейчас называется `-`, отсюда и дефис в ссылке.
> Settings → General → Repository name → переименуйте, например, в `akvagrunt`.
> Адрес станет `https://musicvibes243-commits.github.io/akvagrunt/`.
> После переименования замените старый адрес в трёх местах: `sitemap.xml`,
> `robots.txt` и в `index.html` (строки `canonical`, `og:url`, `og:image`).

## Шаг 2. Подключить приём заявок

Пока каналы не настроены, форма не пропадает: она открывает WhatsApp с уже
заполненным текстом заявки. Это рабочий запасной вариант, но лучше настроить оба канала.

### 2а. Заявки на почту (Formspree, ~5 минут)

1. Зайдите на **formspree.io**, зарегистрируйтесь на бесплатном тарифе
   (50 заявок в месяц).
2. **New form** → укажите почту, куда слать заявки → подтвердите письмо.
3. Скопируйте адрес формы — он выглядит так: `https://formspree.io/f/abcdwxyz`.
4. Откройте `docs/index.html`, найдите строку `formspree: ''` и вставьте адрес:

   ```js
   formspree: 'https://formspree.io/f/abcdwxyz',
   ```

### 2б. Заявки в Telegram (~10 минут)

Пошаговая инструкция — в начале файла `tools/telegram-relay.js`.
Коротко: создать бота у **@BotFather**, узнать свой chat id у **@userinfobot**,
бесплатно завести Cloudflare Worker и вставить туда код из файла.
Полученный адрес вида `https://имя.workers.dev` вписать в `docs/index.html`:

```js
telegram: 'https://имя.workers.dev',
```

> **Почему нельзя проще — вписать токен бота прямо в сайт?**
> Потому что код сайта открыт любому посетителю: правый клик → «Исходный код».
> Токен из кода забирают за минуты, и бот становится чужим. Worker хранит
> токен на сервере, наружу он не выходит.

### 2в. Запасной номер WhatsApp

В том же блоке замените номер на свой, в формате без плюса и скобок:

```js
whatsapp: '79001234567'
```

## Шаг 3. Заменить демо-данные на свои

Откройте `docs/index.html` в любом редакторе (подойдёт Блокнот, но удобнее
[VS Code](https://code.visualstudio.com/) — он бесплатный). Замена по всему
файлу: **Ctrl+H**.

| Найти | Заменить на |
| --- | --- |
| `+7 (495) 123-45-67` | ваш телефон, как он показывается людям |
| `+74951234567` | тот же телефон без пробелов и скобок (для кнопок звонка) |
| `zakaz@akvagrunt.demo` | вашу почту |
| `АкваГрунт` | название вашей компании |
| `Московская область` | ваш регион |
| `60 км от МКАД` | вашу зону выезда |
| `__ФИО ИЛИ НАЗВАНИЕ__`, `__ИНН__` | реквизиты в подвале |

Дальше — по блокам (ищите комментарии заглавными буквами в коде):

- **`<!-- УСЛУГИ -->`** — четыре карточки: описания, характеристики, цены «от».
- **`SERVICES`** в конце файла — цены калькулятора. `base` — базовая стоимость,
  `opts` — доплаты. Меняете числа, расчёт меняется сам.
- **`<!-- ОБЪЕКТЫ -->`** — три «паспорта работ». Поставьте свои реальные объекты:
  грунт, глубина, срок, стоимость. Это самый убедительный блок на странице.
- **`<!-- ОТЗЫВЫ -->`** — сейчас там вымышленные отзывы. **Обязательно замените
  на настоящие или удалите блок целиком.** Выдуманные отзывы — это обман
  клиентов и повод для претензий по закону о рекламе.
- **`<!-- ФАКТЫ -->`** — цифры опыта: сколько объектов, лет, какая гарантия.
- **`<!-- ЧЕРНОВИК -->`** — оранжевая полоса вверху. **Удалите её последней**,
  когда всё остальное заменено.

## Шаг 4. Юридический минимум

1. Откройте `privacy.html` и заполните все места вида `__ТАК__`:
   кто оператор, ИНН, адрес, почта, телефон, сроки хранения, какие сервисы
   получают заявки (Formspree, Telegram).
2. Пропишите реквизиты в подвале `index.html`.
3. Пока вы не зарегистрированы как ИП или самозанятый, сбор персональных
   данных ведётся от вашего имени как физлица — с полной личной ответственностью.
   Зарегистрируйтесь до того, как пойдёт поток заявок.

`privacy.html` — рабочий шаблон, а не юридическое заключение. Если сомневаетесь
в формулировках, покажите текст юристу: за нарушения по 152-ФЗ штрафуют.

## Шаг 5. Статистика посещений

В конце `index.html` есть закомментированный блок Яндекс.Метрики.
Заведите счётчик на metrika.yandex.ru, вставьте его номер вместо `НОМЕР`
и уберите строки-комментарии вокруг блока.

## Чек-лист перед тем, как давать рекламу

- [ ] телефон и почта заменены везде, кнопка звонка работает с телефона;
- [ ] заявка реально доходит — отправьте тестовую сами;
- [ ] цены соответствуют вашему прайсу;
- [ ] отзывы и объекты настоящие;
- [ ] `privacy.html` заполнена, ссылка в форме открывается;
- [ ] реквизиты в подвале на месте;
- [ ] оранжевая полоса «Черновик» удалена;
- [ ] сайт открыт с телефона: всё читается, ничего не уезжает вбок;
- [ ] `og.png` пересобран, если менялись название и телефон
      (`node tools/make-images.mjs`).

## Что уже сделано за вас

- Адаптив: проверено на 390 px (телефон), 768 px и 1360 px, горизонтальной
  прокрутки нет.
- Тёмная тема — включается автоматически по настройке системы.
- Доступность: подписи у полей, видимая рамка фокуса при работе с клавиатуры,
  ошибки формы озвучиваются программами для незрячих, анимации отключаются
  при системной настройке «уменьшить движение».
- Шрифты лежат рядом с сайтом — страница не ждёт ответа от Google.
- Скрытое поле-ловушка отсекает спам-ботов.
- Разметка для поисковиков (schema.org LocalBusiness), карта сайта,
  превью ссылки для мессенджеров.
