# СтройИнвест — сайт

Статический сайт: обычные файлы, которые браузер показывает как есть. Ни базы
данных, ни движка — его нельзя «сломать обновлением» и почти невозможно взломать.
Живёт на GitHub Pages бесплатно.

Посмотреть, не публикуя: откройте `index.html` двойным кликом.

## Что где лежит

```
docs/                     ← это и есть сайт
  index.html              главная: весь текст, стили и скрипты
  privacy.html            политика конфиденциальности (заполнена)
  404.html                страница «такой страницы нет»
  og.png                  картинка ссылки в WhatsApp и Telegram
  favicon.svg             иконка во вкладке браузера
  robots.txt, sitemap.xml подсказки поисковикам
  assets/tokens.css       ЦВЕТА всего сайта — одно место на все страницы
  assets/fonts/           шрифты лежат рядом, Google не нужен
  assets/photos/          фотографии работ + инструкция по загрузке
tools/
  telegram-relay.js       приём заявок в Telegram (инструкция внутри файла)
  og-template.html        макет картинки og.png
  make-images.mjs         пересборка og.png и иконки
```

## Шаг 1. Опубликовать сайт (10 минут, бесплатно)

1. Репозиторий на GitHub → вкладка **Settings** (шестерёнка сверху).
2. Слева в меню — **Pages**.
3. В блоке *Build and deployment*:
   - **Source**: `Deploy from a branch`
   - **Branch**: `claude/laughing-bardeen-64ejnt`, папка — **`/docs`**
   - **Save**.
4. Через 1–2 минуты обновите страницу — вверху появится адрес:
   `https://musicvibes243-commits.github.io/-/`

Дальше каждое изменение в этой ветке обновляет сайт само.

### Свой домен

Сайт живёт по адресу **https://stroyinvest-mo.ru** — домен куплен на reg.ru.
Внутри сайта этот адрес прописан в четырёх местах: `index.html` (строки
`canonical`, `og:url`, `og:image` и блок разметки внизу), `sitemap.xml`,
`robots.txt` и `privacy.html`. При смене домена меняйте во всех.

Чтобы домен работал, у reg.ru в управлении DNS должны стоять четыре записи
типа **A** на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`,
`185.199.111.153` и запись **CNAME** для `www` на
`musicvibes243-commits.github.io`. В настройках Pages домен вписан в поле
**Custom domain**, там же включён **Enforce HTTPS**.

Двенадцать снимков уже стоят в галерее, файлы лежат в `docs/assets/photos/`.
Имена и подписи — в `docs/assets/photos/README.md`.

Чтобы заменить или добавить: репозиторий → папка `docs/assets/photos` →
**Add file** → **Upload files** → перетащить → **Commit changes**.
Фото с телефона весит 3–5 МБ — сожмите до ~150 КБ (например, на squoosh.app),
иначе галерея будет долго открываться с мобильного интернета.

## Шаг 4. Подключить приём заявок

Пока каналы не настроены, форма не теряет клиента: она открывает WhatsApp
с уже заполненным текстом заявки на номер +7 (915) 346-97-28.
Но лучше настроить оба канала — тогда заявка приходит сама.

### 4а. На почту (Formspree, ~5 минут)

1. **formspree.io** → регистрация на бесплатном тарифе (50 заявок в месяц).
2. **New form** → указать почту, куда слать заявки → подтвердить письмо.
3. Скопировать адрес формы вида `https://formspree.io/f/abcdwxyz`.
4. В `docs/index.html` найти `formspree: ''` и вставить:

   ```js
   formspree: 'https://formspree.io/f/abcdwxyz',
   ```

### 4б. В Telegram (~10 минут)

Пошагово — в начале файла `tools/telegram-relay.js`.
Коротко: бот у **@BotFather**, свой chat id у **@userinfobot**, бесплатный
Cloudflare Worker с кодом из файла. Полученный адрес вписать в `index.html`:

```js
telegram: 'https://имя.workers.dev',
```

> **Почему нельзя вписать токен бота прямо в сайт?** Код сайта открыт любому
> посетителю: правый клик → «Исходный код». Токен заберут за минуты.
> Worker хранит токен на сервере, наружу он не выходит.

### Про оформление

Сайт тёмный, тёплый, с одной палитрой на все системные темы — светлой версии
намеренно нет, чтобы вид не «прыгал» у разных посетителей. Все цвета лежат
в `assets/tokens.css`, менять нужно только там.

- **Заголовки** набраны Playfair Display — контрастная антиква с кириллицей.
- **Первый экран** — фотография во всю ширину под затемнением, текст по центру.
  Чтобы поменять снимок: положите свой в `assets/photos/hero.jpg`
  (широкий кадр, примерно 1280×720, до 300 КБ).
- **Галерея** — две колонки, подпись прямо на фотографии. Первые 8 видны сразу,
  остальные открываются кнопкой.
- **Плавная прокрутка** колесом мыши: функция «ПЛАВНАЯ ПРОКРУТКА» в скрипте.
  Отключается удалением этого блока; на телефонах она и так не включается.
- **Появление блоков** при прокрутке и счётчики в полосе фактов — там же в скрипте.
  Всё это выключается системной настройкой «уменьшить движение», без правок кода.

### Про птицу

Летит вместе с прокруткой, при остановке зависает и покачивается.
Силуэт стрижа, вектор (SVG), а не 3D-модель: весит около 2 КБ, не тормозит
телефоны и не требует WebGL. Сама прячется на экранах уже 900 px и при
системной настройке «уменьшить движение».

- **Убрать совсем**: удалите в `index.html` блок `<!-- ПТИЦА -->`, кусок
  стилей `/* птица, летящая со скроллом */` и функцию `ПТИЦА` в скрипте.
- **Цвет**: `--bird-body` и `--bird-wing` в `assets/tokens.css`.
- **Размер**: `.bird{width:clamp(190px,24vw,340px)}` — размер привязан к ширине
  окна, скрипт меряет его сам. Меньше/больше — правьте эти три числа.
- **Скорость взмахов**: `.17s` в правилах `.bird__wing--up/--down`.
- **Траектория**: числа в функции `target()` — множители у `Math.sin`
  задают, сколько раз птица пересечёт страницу по ширине и высоте.

Цен на сайте нет намеренно: стоимость называется после выезда. Если решите
показывать вилку — скажите, добавлю блок так, чтобы это не превращалось
в оферту.
