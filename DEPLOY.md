# Как выложить сайт

Сайт статический: никакой серверной части, только файлы. Подходит любой
хостинг, который умеет отдавать HTML.

## Вариант 1. GitHub Pages — бесплатно, открывается в России

### Быстро, из этого репозитория
1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `claude/dazzling-keller-t4agpr`, папка `/ (root)` → **Save**
4. Через 1–2 минуты сайт живёт по адресу
   `https://<логин>.github.io/<имя-репозитория>/`

### Красивее: отдельный репозиторий
Имя репозитория становится частью адреса, поэтому для красивой ссылки
нужен репозиторий с внятным именем:

1. github.com/new → имя `anikor`, **Public**, без README
2. Залить в него содержимое этого репозитория (index.html, en/, editorial/,
   assets/, .nojekyll) в ветку `main`
3. Settings → Pages → Branch `main`, `/ (root)` → Save
4. Адрес: `https://<логин>.github.io/anikor/`

Проверено: сайт работает из подпапки — все картинки, стили и переключатель
RU/EN используют относительные пути.

## Вариант 2. Свой домен — самый красивый адрес

Домен `.ru` стоит примерно 200–300 ₽ в год (reg.ru, timeweb, beget).
Его можно бесплатно привязать к тем же GitHub Pages:

1. Settings → Pages → Custom domain → ввести домен → Save
2. У регистратора добавить записи:
   - `A` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` для `www` → `<логин>.github.io`
3. Дождаться проверки и включить **Enforce HTTPS**

Адрес становится `https://anikor-yoga.ru` — хостинг бесплатный, платный
только домен.

## Вариант 3. Российский хостинг

Timeweb, Beget, reg.ru: завести тариф, открыть файловый менеджер и
загрузить содержимое репозитория в папку сайта. Работает так же.

## Что важно после публикации

QR-коды в `qr/` ведут на старый адрес. После смены адреса перевыпустить:

```bash
python3 tools/make-qr.py "https://новый-адрес" light
python3 tools/make-qr.py "https://новый-адрес/editorial/" dark
```
