# «Пауза» — демо-сайт студии йоги

Одностраничный демонстрационный макет для студии йоги, у которой пока нет сайта.
Открывается как обычный файл: `projects/yoga-pauza/index.html` — сборка не нужна,
зависимостей нет, весь CSS и JS внутри страницы.

## Что внутри

| Блок | Что показывает |
| --- | --- |
| Первый экран | Позиционирование + панель «сейчас в зале»: занятие, которое идёт прямо сейчас, или ближайшее |
| Расписание | Вкладки на семь дней, время, длительность, уровень, свободные места, кнопка записи |
| Направления | Семь практик с описанием и уровнем |
| Преподаватели | Три карточки с квалификацией и цитатой |
| Абонементы | Разовое, 8 занятий, безлимит + первое занятие |
| Студия | Факты о зале, правила прихода, интерактивная практика дыхания «сама вритти» |
| Вопросы | Пять частых вопросов |
| Контакты | Адрес, метро, телефон, почта, часы работы |
| Запись | Модальное окно с формой (демо — заявка никуда не отправляется) |

## Что нужно заменить перед боевым запуском

- Название, адрес, метро, телефон, почта и часы — сейчас условные.
- Расписание, преподаватели и цены — в массиве `SCHEDULE` и в разметке.
- Фотографии зала и преподавателей: вместо портретов сейчас типографские плашки
  с инициалами (`.tch__port`).
- Форма записи не отправляет данные — нужен обработчик или CRM/виджет записи.

## Оформление

- Палитра: бледный камень `#ECECE6`, глубокий мох `#1E3B31`, приглушённое золото
  `#B98C1E` — только на маркерах занятости и акцентах.
- Шрифты: Tenor Sans (заголовки), Golos Text (текст), JetBrains Mono (время, цены).
- Светлая и тёмная темы через токены `:root`, `prefers-color-scheme` и `data-theme`.
- Адаптив от 360px, движение уважает `prefers-reduced-motion`.
