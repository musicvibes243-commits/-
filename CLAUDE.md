# Репозиторий: сайт СтройИнвест

Один проект — сайт монтажника септиков, кессонов и дренажа по Москве
и Московской области. Статический, без сборки: `docs/` — это и есть сайт.
Инструкция для владельца — `docs/README.md`.

## Публикация — не менять без просьбы владельца

GitHub Pages публикует **ветку `claude/laughing-bardeen-64ejnt`, папку `/docs`**,
домен — **stroyinvest-mo.ru** (куплен на reg.ru, файл `docs/CNAME`).

Один репозиторий на GitHub публикует только один сайт. 11–12 сентября 2026
настройку Pages переключили на ветку другого проекта — в её опубликованной
папке не было `CNAME`, домен отвязался, и сайт отдавал 404 больше суток,
пока владелец не вернул настройку руками.

Поэтому: **не переключайте источник Pages на другую ветку и не удаляйте
`docs/CNAME`.** Другому проекту нужен свой репозиторий. Сайт рекламируется
за деньги в Яндекс Директе — часы простоя стоят владельцу заявок.

## Что подключено снаружи

| Что | Где | Примечание |
| --- | --- | --- |
| Заявки в Telegram | Cloudflare Worker `zayavki` | адрес в `DELIVERY.telegram`, токен бота — секрет воркера |
| Яндекс.Метрика | счётчик 112522751 | номер в `var METRIKA` в конце `index.html` |
| Домен | reg.ru → четыре A-записи GitHub Pages | `www` — CNAME |

Токенов и паролей в репозитории нет и быть не должно: код сайта открыт
любому посетителю.

## Чего на сайте нет намеренно

- **Цен.** Стоимость называется после выезда — так решил владелец.
- **Почты.** Связь только по телефону, WhatsApp и Telegram.
- **Юридического адреса на главной.** Работа выездная по Московской области,
  а адрес ООО — в Чувашии; он есть только в политике, как требует закон.
- **Отзывов и «10 лет на рынке».** ООО зарегистрировано 22 июня 2026 года,
  и это видно в ЕГРЮЛ. Опыт на сайте всегда привязан к мастерам, а не
  к компании: «опыт мастеров 10+ лет». Не переписывайте это на «компания
  на рынке 10 лет» — поймают на противоречии.

## Владелец — не программист

Объясняйте по шагам, называйте кнопки так, как они подписаны на экране,
и говорите, чего делать не надо. Правки вносите в репозиторий сами
и пушьте — владелец проверяет результат на живом сайте с телефона.
