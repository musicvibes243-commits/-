# Как запустить сайт с ИИ-помощником

В папке:

| Файл или папка | Что это |
| --- | --- |
| `index.html` | сам сайт |
| `privacy.html` | политика конфиденциальности (нужна для рекламы и формы заявки) |
| `img/` | скриншоты работ и картинка для ссылки в соцсетях |
| `netlify/functions/chat.js` | связь с Claude для ИИ-помощника |
| `netlify/functions/lead.js` | заявки в Telegram (по желанию) |
| `netlify.toml`, `robots.txt` | настройки публикации |

Рядом с папкой сайта лежит папка `ayko-direct` — всё для запуска рекламы. Её **не нужно**
загружать на Netlify: это ваши рабочие материалы, в интернете им делать нечего.

## 1. Получите ключ Claude
1. Зайдите на console.anthropic.com и создайте аккаунт.
2. Пополните баланс на небольшую сумму и в настройках задайте лимит расходов.
3. Раздел API Keys → Create Key. Скопируйте ключ (он показывается один раз). Никому его не отправляйте и не вставляйте в код.

## 2. Опубликуйте на Netlify
1. Распакуйте архив.
2. На app.netlify.com: Add new site → Deploy manually. Перетащите всю папку `ayko-ai`.
3. Site configuration → Environment variables → Add a variable: `ANTHROPIC_API_KEY` = ваш ключ.
4. Deploys → перетащите папку ещё раз (или Trigger deploy), чтобы ключ подхватился.
5. Откройте сайт, нажмите «Спросить помощника» и задайте вопрос.

Если в разделе Functions пусто и помощник отвечает «Не получилось ответить», загрузите проект через GitHub (Add new site → Import from Git) или командой `netlify deploy --prod` (Netlify CLI).

Это отдельный новый сайт. «Симба» и другие ваши сайты на Netlify не затрагиваются.

## 3. Заявки в Telegram (по желанию)
1. В Telegram напишите @BotFather, команда `/newbot`, получите токен.
2. Напишите своему боту любое сообщение, откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `chat` → `id`.
3. В Netlify добавьте переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, переопубликуйте.

Без этого заявки открывают письмо на почту из `index.html` (переменная `EMAIL`).

## Что поменять в index.html

В файле два блока настроек.

**Вверху, в `<head>` — «НАСТРОЙКИ РЕКЛАМЫ И АНАЛИТИКИ»:**

| Строка | Зачем |
| --- | --- |
| `METRIKA_ID` | номер счётчика Яндекс.Метрики. Пусто — счётчик не грузится |
| `SITE_URL` | адрес сайта, например `https://ayko-web.ru`. Пусто — берётся текущий |
| `PHONE` | телефон для звонка. Пусто — строка «Телефон» в контактах скрыта |
| `LEGAL` | реквизиты в подвале, например `Самозанятый Иванов И. И., ИНН 500000000000` |

**Ниже, перед основным кодом — «НАСТРОЙКИ»:** `EMAIL`, `TELEGRAM`, `WHATSAPP`, `MAXLINK`, `VK`, `INSTAGRAM`, `REVIEWS`.

В `privacy.html` есть строка `OPERATOR` — впишите туда те же реквизиты, что в `LEGAL`.

## Реклама в Яндекс.Директе

Всё готовое лежит в соседней папке `ayko-direct`: тексты объявлений, 139 ключевых фраз,
127 минус-слов, картинки для РСЯ и пошаговая инструкция в `ayko-direct/README.md`. Сайт уже подготовлен —
есть политика конфиденциальности, согласие на обработку данных в форме, счётчик Метрики
и цели, по которым Директ учится приводить заявки.

## Что знает помощник
Всё в тексте `SYSTEM` в файле `netlify/functions/chat.js`: цены, сроки, процесс, примеры работ. Изменили цену на сайте, измените и там.

## Полезно знать
- По умолчанию модель `claude-haiku-4-5-20251001` (недорогая). Другую можно указать переменной `CLAUDE_MODEL`.
- Скриншоты работ лежат отдельными файлами в `img/`. Если замените их, оставьте те же имена — или поправьте блок `IMG` в `index.html`.
- `img/og.jpg` — картинка, которая показывается, когда ссылку на сайт кидают в мессенджер.
- Функция ограничивает длину сообщений и частоту запросов. Чтобы принимать запросы только с вашего сайта, добавьте переменную `ALLOWED_ORIGIN` (например, `https://ваш-сайт.netlify.app`).
- Помощник отвечает только по фактам из `SYSTEM`. Иногда проверяйте его ответы.
