# Портфолио: карточки сайтов

Карточки 1600×1000 — сайт в окне браузера и он же в телефоне. Тёмный фон,
чтобы светлые сайты читались ярче и чтобы карточки без переделки вставлялись
в PDF-прайс.

| Файл | Что это |
|---|---|
| `karta-atelier.jpg` | Atelier, школа портного и швейный коворкинг в Королёве |
| `karta-atelier-2.jpg` | Atelier, второй вариант главной |
| `karta-ayko.jpg` | AYKO — её собственный сайт |
| `karta-ayko-cosmos.jpg` | AYKO, вариант оформления «Космос» |
| `karta-savva.jpg` | SAVVA, кофейня в Медине: русский, английский, арабский |
| `karta-savva-arka.jpg` | SAVVA, демо-макет «Арка» |
| `karta-savva-vitrina.jpg` | SAVVA, демо-макет «Витрина» |
| `karta-savva-gazeta.jpg` | SAVVA, демо-макет «Газета» |

Исходные снимки — в `snimki/`, по два на сайт: `-monitor.jpg` и `-telefon.jpg`.

Пересобираются: `node dnevnik/avito/portfolio-snimki.js` (нужен локальный
сервер на 8777), затем `node dnevnik/avito/portfolio-kartochki.js`.

**Три макета SAVVA подписаны как демо** — это варианты оформления, а не
работающие сайты. Выдавать их за сделанное нельзя.

**С карточек ателье стёрт телефон заказчицы.** Он стоял в шапке сайта и
попадал в PDF-прайс, который раздают посторонним. Стирает
`python3 dnevnik/avito/zateret-nomera.py` — не пятном, а заливкой фоном
самого сайта. Если карточки пересобирать из снимков, скрипт надо
прогнать заново.
