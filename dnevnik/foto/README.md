## Карточки для канала

Лежат в `kartochki/`. Делаются генератором `dnevnik/kartochki/generate.js`
из файла `cards.json`: там текст, а картинка собирается сама, в цветах сайта.

| Файл | Цифра на карточке |
| --- | --- |
| `reklama-pervye-dva-dnya.jpg` | 278 / 3 / 0 — первые два дня рекламы |
| `kuda-ushli-dengi.jpg` | 128 ₽ из 162 ушли на ненужные клики |
| `sayt-stal-legche.jpg` | 454 → 157 КБ, первый экран стал легче втрое |
| `tri-vechera.jpg` | 3 вечера поисков, почему не открывался домен |
| `cena.jpg` | 15 000 ₽, цена названа до начала работы |

Нужна новая — скажите фразу и цифру, я допишу строку в `cards.json`
и перерисую. Размер 1080×1350, как раз под телеграм.

## Как добавить сюда новое

Пришлите фотографию в чат и скажите: «сохрани в дневник, это такой-то проект».
Я положу её сюда и допишу строку в эту таблицу. Сама по себе картинка
из переписки в папку не попадает.

⚠️ Для картинок в рекламу: на снимке `ayko-direct/creatives/rsya-16x9.jpg`
виден чужой телефон в шапке сайта ателье. Яндекс такое отклоняет,
и клиент может быть не рад. Перед публикацией — закрывать.
