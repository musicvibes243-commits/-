# Запас мемов

Всё, что Айым присылала, с нормальными именами. Пятьдесят пять штук.
Отсюда берутся картинки для новых роликов: кладёте двенадцать (или
сколько нужно) в новую папку, нумеруете по порядку строк, запускаете
отрисовку.

Разложено по смыслу — так искать быстрее, чем листать.
