# Ролик «Семь тысяч за пустоту»

`dnevnik/foto/ril-hosting-bez-zvuka.mp4` — 1080×1920, 38,3 с, h264, 30 кадров,
631 КБ. Звуковая дорожка пустая: без неё часть приложений ролик не принимает.

Собирается в два шага:

    node dnevnik/avito/ril-hosting.js      # рисует кадры и список длительностей
    ffmpeg -f concat -safe 0 -i .../spisok.txt ...   # склеивает

Длительность каждого кадра считается из числа слов (2,8 слова в секунду) плюс
отдельная пауза на смысловых точках — «Там не было ничего», «Напишите РАЗБОР».
Кегль подбирается сверху вниз, пока текст не влезет в поле; если не влезает
даже мелким, сборка падает, а не выпускает обрезанный кадр.

**Чего в ролике нет и почему**

Настоящих скриншотов Beget: контейнер пересоздавался, и присланные файлы
не сохранились. Рисовать похожее письмо нельзя — это была бы подделка письма
реальной компании.

Голоса и музыки: голос записывает Айым сама, музыку выбирает в редакторе
Reels из встроенной — так площадка её и продвигает.
