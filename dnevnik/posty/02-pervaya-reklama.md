# Пост 2. Первые цифры рекламы. Честный

Сильный пост: показывает не успех, а работу. Такому верят.
Цифры настоящие, из кабинета Директа за 22–23 сентября.

```
Запустила рекламу на свой сайт. Показываю первые цифры,
не дожидаясь, пока они станут красивыми.

За два дня:
278 показов
3 клика
91 рубль потрачен
0 заявок

Ноль заявок с трёх кликов — это не провал, это просто ноль.
Чтобы получить одну заявку, нужно человек двадцать-тридцать.
Три клика не говорят вообще ничего.

А вот что сказал отчёт по запросам, и это интереснее.
Из 162 рублей, потраченных за неделю, 128 ушло на два клика,
которые мне не нужны были совсем. Один человек искал
«сделать сайт» — общий запрос, который я специально
не брала, его притащил автоподбор Яндекса. Второй искал
портфолио для фотографов, а не того, кто им сайт сделает.
Этот клик стоил 86 рублей.

То есть на разговор с настоящими клиентами ушло два клика
и 33 рубля. Двое людей. По двум людям выводов не делают.

Что делаю дальше: добавляю минус-слова, чтобы не платить
за такие запросы, и даю кампании неделю. Потом покажу,
что получилось.

Мой сайт: aykoweb.ru
```
