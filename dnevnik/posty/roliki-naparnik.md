# Ролики о поиске напарника

Один текст, пять наборов картинок. 1080×1920, звука нет — музыку
выбирать в самом ТикТоке.

| Файл | Картинки |
|---|---|
| `ril-naparnik.mp4` | только надписи на тёмном фоне |
| `ril-naparnik-foto.mp4` | постановочные кадры, девушка в розовом |
| `ril-memy.mp4` | мемы: Гэтсби, «Офис», Губка Боб, Хасбулла |
| `ril-memy2.mp4` | мемы: Тони Старк, Шрек, CJ, Барашек Шон |

| `ril-memy4.mp4` | **короткий, 21 секунда** — таксы, обезьяны, крыса |

## Текст

Отдам половину денег / тому, кто умеет продавать / Я делаю сайты /
Ботов и мини-приложения / Проще три дня писать код, чем набрать номер /
Поэтому ищу напарника / Вы находите клиента и договариваетесь /
Всё остальное делаю я / 50% с первой оплаты / 20% с каждого месяца /
Оклада нет. Вложений тоже / Напишите НАПАРНИК

Описание и хештеги — в `ril-naparnik.txt`.

## Короткая версия

`ril-memy4.mp4` — тот же смысл в семи кадрах вместо двенадцати, 21
секунда вместо 31. Короткие ролики досматривают чаще, а досмотры и
решают охват. Текст сжат: «Я делаю сайты и ботов», «Вы находите
клиента — остальное на мне», «50% с первой оплаты, дальше 20%».

## Как собрать ещё один

    node dnevnik/avito/ril-memy.js <папка>
    bash dnevnik/avito/ril-naparnik-sborka.sh <папка>-holsty <имя ролика>

Картинки в папке нумеруются по порядку строк. Кадров может быть сколько
угодно: по умолчанию берётся сценарий на двенадцать строк, но если
положить рядом `kadry.json` со своим текстом, ролик соберётся по нему.
Длительности считаются по числу слов и кладутся рядом с холстами, склейка
их только читает.

Проверки не дадут собрать ролик, если мем занимает меньше пятой части
кадра, если текст не влезает или если число кадров разошлось с числом
длительностей.

## Как выкладывать

По одному раз в три-четыре дня, среда или четверг в 10 утра по Москве —
это лучшие часы по статистике аккаунта. Повтором ТикТок это не считает:
картинки разные.

Смотреть не лайки, а досмотры: какой набор держит до конца, в ту
сторону и снимать дальше.
