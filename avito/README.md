# Объявление на Авито — «Разработка сайтов»

10 изображений (1800×2400 px, PNG) + запасной слайд и готовый текст объявления.

Комплект собран в **двух темах** — макеты и тексты одинаковые, отличается только оформление:

| Тема | Папка | Как выглядит |
|------|-------|--------------|
| Жёлтая | `images/` | Жёлтый градиент, чёрный гротеск, красные акценты — как в исходном референсе |
| Тёмная | `images-lux/` | Чёрный фон, золото, антиква Playfair Display — «люксовый» стиль |

Для объявления берите одну из них целиком, не смешивая.

## Как изменить макеты

Тексты и вёрстка — общие для обеих тем, в `posters.html`.
Оформление: `styles.css` (жёлтая) и `styles-lux.css` (тёмная, подключается поверх первой).

```bash
npm i -D playwright          # один раз, если playwright не установлен
node avito/render.mjs        # обе темы
node avito/render.mjs lux    # только тёмную
```

Шрифты: Montserrat, Playfair Display, Bad Script, Marck Script (Google Fonts, кириллица). Они должны быть установлены в системе — макеты рендерятся системными шрифтами.

### Подтёки (слайд 14)
`assets/drip.png` вырезан из исходного снимка скриптом:

```bash
node avito/tools/cutout-drip.mjs <исходник.jpg> avito/assets/drip.png
```

Скрипт обрезает всё, кроме жёлтой массы, делает внешний фон прозрачным заливкой
от краёв (блики внутри массы сохраняются) и снимает светлый ореол по контуру.
Подтёки лежат слоем выше заголовка, поэтому натекают прямо на буквы.

- Цену «15 тыс» — в `posters.html` (слайды 01 и 10).

- На слайде 10 можно добавить телефон или ник в мессенджере.
