# Объявление на Авито — «Разработка сайтов»

Десять слайдов объявления (1800×2400 px, PNG) + запасные макеты и готовый текст объявления.

Комплект собран в **двух темах** — вёрстка и тексты одинаковые, отличается оформление:

| Тема | Папка | Как выглядит |
|------|-------|--------------|
| Жёлтая | `images/` | Жёлтый градиент, чёрный гротеск, красные акценты |
| Тёмная | `images-lux/` | Чёрный фон, золото, антиква Playfair Display |

Для объявления берите одну тему целиком, не смешивая.

## Как пересобрать

Тексты и вёрстка всех слайдов — в `posters.html`, оформление — в `styles.css`
(жёлтая тема) и `styles-lux.css` (тёмная, подключается поверх первой).
Порядок десяти слайдов задаётся массивом `MAIN` в `render.mjs` — слайд, которого
там нет, уходит в `extra/`.

```bash
npm i -D playwright          # один раз, если playwright не установлен
node avito/render.mjs        # обе темы
node avito/render.mjs lux    # только тёмную
```

Превью всех макетов с переключателем тем: откройте `index.html` в браузере.

Шрифты: Montserrat, Playfair Display, Bad Script, Marck Script (Google Fonts, кириллица) —
должны быть установлены в системе, макеты рендерятся системными шрифтами.

### Вырезание объектов с фотографий

Кот, звезда и подтёки вырезаны из присланных снимков скриптами:

```bash
node avito/tools/cutout.mjs <src> <out.png> [r,g,b] [sat] [trim]
node avito/tools/cutout-drip.mjs <src> <out.png>
```

`cutout.mjs` убирает светлый фон заливкой от краёв (блики внутри объекта сохраняются),
снимает ореол по контуру и обрезает по границам объекта; `trim` дополнительно отсекает
оторванные куски снизу (например, тень под предметом). `cutout-drip.mjs` — то же самое
для скриншота с подтёками, с обрезкой интерфейса телефона.

### Что стоит подставить своё
- Цену и срок акции — в `posters.html` (слайды `cover` и `final-cta`).
- Круглый бейдж «2 дня» внизу справа — сюда удобно поставить свой логотип (блок `.mark`).
- На финальном слайде можно добавить телефон или ник в мессенджере.
- `assets/portfolio-sites.png` — веер ваших работ, заменяется своим PNG с прозрачным фоном.
