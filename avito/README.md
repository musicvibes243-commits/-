## Как изменить макеты

Тексты и вёрстка — в `posters.html`, оформление — в `styles.css`.

```bash
npm i -D playwright      # один раз, если playwright не установлен
node avito/render.mjs    # пересобрать PNG в avito/images/
```

Шрифты: Montserrat, Playfair Display, Bad Script (Google Fonts, кириллица). Они должны быть установлены в системе — макеты рендерятся системными шрифтами.

### Что стоит подставить своё
- Цену «15 тыс» — в `posters.html` (слайды 01 и 10).
- Круглый бейдж «2 дня» внизу справа — сюда удобно поставить свой логотип (блок `.mark`).
- На слайде 10 можно добавить телефон или ник в мессенджере.
