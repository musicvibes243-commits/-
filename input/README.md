# Сюда класть исходники

Папка для сырых видео, которые нужно смонтировать.

## Как загрузить с телефона

1. Открыть https://github.com/musicvibes243-commits/-/upload/claude/shorts-clips-instagram-tiktok-onyx2t/input
2. «Choose your files» → выбрать видео
3. Внизу «Commit changes»

## Требования к файлам

- **Формат — MP4.** Сырые файлы камеры (`.insv`, `.insp`, `.mov` с телефона) грузить не надо:
  сначала экспорт в MP4 из приложения камеры.
- **Не больше 25 МБ на файл** — это лимит загрузки через сайт GitHub.
  Один кусок 20–30 секунд в 1080p как раз укладывается.
- **Резать на куски заранее.** Девятиминутный файл сюда не влезет и не нужен:
  лучше 2–3 отобранных отрезка по 20–40 секунд.
- Если снято на 360-камеру — либо экспорт уже кадрированный в 9:16,
  либо экспорт в 360 (equirectangular), тогда ракурс подбирается при монтаже.

## Субтитры

Если есть расшифровка речи — положить сюда же файл `.srt` рядом с видео,
имя то же, что у ролика. Автосубтитры из CapCut подойдут, термины поправлю сам.
