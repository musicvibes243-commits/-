# Сюда класть исходники

Папка для сырых видео, которые нужно смонтировать.

## Основной способ — просто прислать файл в чат

Работает и проще всего. Единственное требование — файл должен быть небольшим
(ориентир: до 20 МБ). Как этого добиться — см. «Как уменьшить файл» ниже.

## Запасной способ — загрузить сюда, на GitHub

Прямую ссылку на загрузку в этом репозитории использовать НЕЛЬЗЯ: у всех веток
в имени есть слэш (`claude/...`), и GitHub принимает часть имени ветки за путь.
Идти надо кликами, тогда адрес соберётся сам:

1. Открыть https://github.com/musicvibes243-commits/-
2. Переключатель веток вверху слева → выбрать `claude/shorts-clips-instagram-tiktok-onyx2t`
3. Зайти в папку `input`
4. Кнопка «Add file» → «Upload files»
5. Внизу «Commit changes»

Лимит загрузки через сайт — **25 МБ на файл**.

## Как уменьшить файл

- **Сначала обрезать, потом экспортировать.** Кусок 15–30 секунд, а не весь материал.
- **Экспорт в 1080p**, не в 4K и не в 5.7K. Разницы после пережатия соцсетями не будет,
  а вес падает в разы. Апскейл и резкость я вытяну сам.
- Если приложение камеры не даёт выбрать разрешение — прогнать через CapCut:
  импорт → обрезать → «Экспорт» → 1080p / 30 fps.

Ориентир: 15 секунд в 1080p — примерно 8–15 МБ.

## Требования к формату

- Только **MP4**. Сырые файлы камеры (`.insv`, `.insp`) не принимаются нигде:
  сначала экспорт из приложения.
- Если снято на 360-камеру — либо экспорт уже кадрированный в 9:16,
  либо экспорт в 360 (equirectangular), тогда ракурс подбирается при монтаже.

## Субтитры

Если есть расшифровка речи — положить рядом файл `.srt` с тем же именем.
Автосубтитры из CapCut подойдут, термины поправлю сам.
