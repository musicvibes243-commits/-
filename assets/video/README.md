# Видео для первого экрана

Положите сюда `hero.mp4` (лучше 1080p, до ~8 МБ, без звука) и укажите путь
в `assets/js/main.js`:

```js
var HERO_VIDEO = 'assets/video/hero.mp4';
```

Пока строка пустая, фоном остаётся фотография зала — она же служит постером,
пока видео грузится, и запасным вариантом, если браузер его не проиграет.
При включённом «уменьшить движение» видео не подключается вовсе.
