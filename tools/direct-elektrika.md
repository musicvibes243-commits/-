# Кампания в Директе: электрика, только поиск

Пошагово, чтобы не листать соседний файл. Всё в рамках можно копировать.

Файл лежит в `tools/`, на сайт не публикуется.

## Шаг 1. Создать

**«Добавить»** → **«Кампанию»** → **«Режим эксперта»** → цель
**«Конверсии, продажи и трафик»**.

## Шаг 2. Настройки кампании

Название:

```
Электрика — поиск
```

Ссылка на сайт:

```
https://stroyinvest-mo.ru/elektrika.html
```

| Поле | Значение |
| --- | --- |
| Стратегия | Максимум кликов |
| С оплатой | За клики |
| Бюджет | В неделю, `3000` ₽ |
| Ограничение расхода | Средняя цена клика |
| Средняя цена клика | `120` ₽ |
| Счётчик Метрики | `112522751` (подтягивается сам) |

**Меньше 3 000 ₽ в неделю Директ не принимает** — с сентября подняли
минимум, и старые 2 100 ₽ в новую кампанию уже не вписать. У отопления
2 100 остались как есть: правило действует на новые кампании.

**Целевые действия:** «Отправка заявки» и «клик по телефону»,
ценность у обеих `3000` ₽. Не `120` и не бюджет: это соседние поля
и цифры в них путаются. Смотрите на подпись над полем.

**Четыре переключателя, каждый важен:**

| Переключатель | Как надо |
| --- | --- |
| **Места показа** | **только «Поиск»** — главное на всём экране |
| Коллтрекинг | выключить |
| «Автоматически применять рекомендации» | снять |
| «Резервная посадочная страница» | снять |

Регионы показа: Москва **и** Московская область.

**Отметить «Быстрые ссылки» и «Уточнения»**, в быстрых ссылках нажать
«Добавить ещё» три раза — нужно четыре строки.

| Наши работы | Фото с объектов: щиты, разводка, подрозетники | `https://stroyinvest-mo.ru/elektrika.html#raboty` |
| Частые вопросы | Нужен ли проект, какой кабель, кто подключает к сетям | `https://stroyinvest-mo.ru/elektrika.html#voprosy` |
| Оставьте заявку | Ответим и приедем на замер бесплатно | `https://stroyinvest-mo.ru/elektrika.html#zayavka` |

Уточнения, по одному:

```
Выезд бесплатно

```

Сумма 64 знака из 66 — покажутся все четыре. «Медный кабель»
и «Подписываем щит» взяты со страницы: там обещано не ставить алюминий
и подписывать каждую линию. Этого не пишут конкуренты, и это проверяется
на сдаче.

## Шаг 3. Группа

Название:

```
Электрика — общие
```

География — Москва и область. Сценарий группы — «Вся заинтересованная
аудитория».

**Автотаргетинг целиком не выключается**, вместо тумблера восемь
галочек. Оставить отмеченными только две:

| Галочка | Что делать |
| --- | --- |
| Целевые запросы | оставить |
| Узкие запросы | снять |
| **Широкие запросы** | **снять** — самая дорогая: человек ищет «построить дом», показывают электрику |
| Сопутствующие запросы | снять |
| Альтернативные запросы | снять |
| Запросы с упоминанием вашего бренда | оставить |
| **Запросы с упоминанием брендов конкурентов** | **снять** — человек уже выбрал, к кому идёт |
| Запросы без упоминания брендов | оставить |

## Шаг 4. Ключевые фразы

Вставить **один раз**. Если вставится дважды, каждая строка покраснеет
«Ключевые фразы должны быть уникальны» и группа не сохранится. Лечится
кнопкой из трёх точек над блоком → «Редактировать списком» → Ctrl+A,
Delete, вставить заново.

```
монтаж электрики в частном доме
электрика под ключ в доме
электромонтаж в частном доме

монтаж проводки в частном доме
ввод электричества в дом

освещение участка под ключ

электромонтажные работы в доме
```


`квартире` и `квартира` отсекают городские заказы — вы работаете
в частных домах. `счетчик` и `подключение к сетям` — работа сетевой
организации, а не ваша; на странице так и написано.

В это поле — только слова, ничего больше: посторонний текст Директ
разобьёт на отдельные минус-фразы. Косую черту не ставить: `бу`,
не `б/у`.

## Шаг 6. Объявление

Тип — **«Комбинаторное»**, стоит первым и уже выбрано. Привычного
«текстово-графического» в списке больше нет.

**«Нейрообъявление» не выбирать** — там Яндекс сочиняет текст по сайту
сам и не знает, что писать «компания 10 лет на рынке» нельзя, а надо
«опыт мастеров 10+ лет».

Ссылка на продвигаемую страницу:

```
https://stroyinvest-mo.ru/elektrika.html
```

Отображаемая ссылка: `elektrika`. Параметры URL оставить пустыми.

**«Заголовки» — одно общее поле, до семи штук.** Отдельного «второго
заголовка» нет: показывается один заголовок из списка, поэтому каждый
должен читаться сам по себе. Лимит 56 знаков.

```
Электрика в частном доме под ключ
Электромонтаж в доме и на участке
Сборка щита и разводка по дому
Электрика для дома в Москве и области
Монтаж электрики в загородном доме
Электрик в Подмосковье — щит, розетки, свет
```

**«Тексты» — отдельное поле ниже**, до трёх, минимум один, лимит 81.

```
Щит, разводка, ввод на участок, освещение. Каждую линию проверяем под нагрузкой
Розетки, свет и мощная техника — на отдельных автоматах. Схема групп на замере
Электрику, отопление и воду ведём одной бригадой — траншеи и штробы общие
```

Заголовки и тексты легко перепутать местами — они идут вплотную.
Смотрите на подпись над полем, а не на порядок.

Ни один текст не повторяет уточнения: уточнения приклеиваются
и к заголовку, и к тексту, и повтор виден только в предпросмотре.

## Шаг 7. Изображения

По электрике на сайте три снимка — это самое тонкое место кампании.

```
ffmpeg -i docs/assets/photos/shchit-avtomaty-01.jpg \
       -vf "crop=720:720:0:120" -q:v 2 elektrika-1-shchit.jpg
ffmpeg -i docs/assets/photos/shchit-uzo-01.jpg \
       -vf "crop=720:720:0:120" -q:v 2 elektrika-2-uzo.jpg
ffmpeg -i docs/assets/photos/razvodka-komnata-01.jpg \
       -vf "crop=540:540:90:0"  -q:v 2 elektrika-3-razvodka.jpg
```

Видео не грузим: Яндекс соберёт видеодополнение из картинок сам.

**Доснять:** распаячную коробку с укладкой, кабель в траншее до засыпки
и фонари на участке вечером. Вечерний кадр с горящими фонарями — самый
продающий для освещения, и его нет. Снимать горизонтально, инструмент
из кадра убрать.

## Шаг 8. Сохранить и отправить на модерацию

Модерация обычно несколько часов, иногда до суток. Завернут — прислать
текст отказа, перепишем.

## Счёт в Директе общий

Отдельных кошельков по кампаниям нет. С электрикой в кабинете
`damka9093` настроено откручивать:

```
2 100 ₽  отопление
5 000 ₽  сайты по нишам (другой бизнес владелицы)
3 000 ₽  электрика
────────
10 100 ₽ в неделю
```

Потолок и реальный расход — разные вещи: за первые сутки отопление
сняло 435 ₽, сайты 51 ₽. Но если деньги кончатся, встанут **все** три
разом, включая ту, что приносит заявки.

Поэтому баланс смотреть раз в два-три дня, а не раз в две недели.
Падает быстрее чем на тысячу в день — пополнять или снижать бюджет
кампании на сайты.

## Правило остановки

```
расход ÷ (заявки с формы + клики по телефону + звонки «нашли в Яндексе») = цена заявки
```

Дешевле 3 000 ₽ — продолжаем. Дороже — выключаем.

С тремя кампаниями вопрос «где вы нас нашли» становится обязательным:
иначе не понять, какая приносит заявки, а какая ест бюджет.
