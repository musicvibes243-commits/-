# Сколько потрачено на сайт и рекламу

Записка для отчёта. Сайт начали делать **9 сентября 2026**, считаем с этой
даты.

Файл лежит в `tools/`, на сайт не публикуется.

## Сначала одно различие, иначе цифры не сойдутся

**Внесено на счёт** и **потрачено** — разные суммы. На счёте Яндекс
Директа лежат деньги, которые ещё не откручены: они ваши и вернутся,
если кампании выключить. Отчитываться надо за потраченное.

```
внесено − остаток на балансе = потрачено
```

Обе цифры полезны: первая показывает, сколько ушло с карты, вторая —
сколько реально съела реклама.

## Авито: 4 097,81 ₽ за сентябрь, ноль обращений

Цифра с экрана «Профессиональный план» → «Результат за сентябрь»,
снято 28 сентября:

| | |
| --- | --- |
| Просмотров получено | **75** |
| Рублей потрачено | **4 097,81 ₽** |
| Открытий контактов | **0** |
| Чатов и звонков | **0** |

**Около 55 ₽ за один просмотр объявления** — не за звонок, за показ
картинки в ленте.

**Почему так:** в блоке «Куда выезжаете» у Авито всего два варианта —
«Не выезжаю» и «По всему городу». Варианта «по области» нет. Значит
объявления видели только в Королёве, а Королёв — город многоэтажек.
Человек, которому нужен септик или дренаж, живёт в частном доме
в посёлке. Мы показывали рекламу тем, у кого нет участка.

На 28 сентября осталось 1 924,47 ₽ аванса; объявления скрываются,
когда остаётся меньше 427,5 ₽. Лимит трат на день не установлен.

**Решение: план приостановить.** Не потому что дорого, а потому что
при такой географии он не может сработать.

Подробные списания, если понадобятся: **Профиль** → **Кошелёк** →
**История операций**.

На Авито по объявлению об отоплении настраивали: бюджет 300 ₽ в день,
максимальная цена за просмотр контактов 250 ₽. Списывают только когда
человек открыл номер телефона, поэтому расход зависит от того, сколько
людей это сделали.

**Это плохой результат, и записан он здесь именно так.** Метрика

Почему так вышло, четыре причины, честно:

1. **Месяц ушёл на постройку, а не на продажи.** Сайт, страницы,
   кампании, профиль. Всё нужное, но заказ само по себе не приносит.
2. **Сезон.** Конец сентября — хвост для септиков и дренажа, их ставят
   с апреля по август. Водоснабжение и автополив не запускали вовсе.
3. **Денег в рекламе мало, чтобы что-то увидеть.** 14 тысяч за месяц
   в Москве и области — это триста кликов. Конкуренты тратят столько
   за два дня.
4. **Авито показывалось не той аудитории** — см. раздел выше.

## Что получено за эти деньги

Чтобы отчёт был не только про расход:

- сайт из шести страниц: главная, дренаж, водоснабжение, отопление,
  электрика, автополив — с фотографиями и видео с реальных объектов;
- заявки приходят в Telegram, звонки на телефон;
- Метрика считает заявки и клики по телефону, настроены четыре цели;
- карточка в Яндекс Бизнесе с живым отзывом, дубли убраны;
- профиль исполнителя на Авито: **рейтинг 5,0, девять отзывов**;
- четыре поисковые кампании в Директе, все без РСЯ;
- объявление на Авито.

**Результат за первую полную неделю (21–27 сентября):**
три строительные кампании дали **13 целевых действий за 5 404,98 ₽**,
то есть по **416 ₽** при пороге остановки 3 000 ₽. Лучшая — электрика:
7 действий по 250 ₽, у отопления 6 по 320 ₽. Дренаж не дал ни одного
с 75 кликов.

Для сравнения: сентябрьская кампания на септики за 2 100 ₽ дала
149 кликов и **ноль** — разница в снятой галочке РСЯ и в сезоне услуги.

**Важно для отчёта: 13 целевых действий — это НЕ 13 заявок.**

28 сентября проверили напрямую. Директ показал у электрики 6 конверсий
по цели «клик по телефону» за утро — мастер сказал, что телефон
не звонил ни разу. Значит цель считает касания номера: липкую панель
внизу экрана задевают пальцем, а на компьютере по номеру кликают,
чтобы скопировать.

**В отчёт мужу цифру «13 заявок» не писать.** Писать так:

- расход — точный, его видно в Директе;
- заявки — только те, что подтверждаются: сообщения в телеграме,
  сообщения в WhatsApp, звонки, которые мастер помнит.

Расход — факт. Всё остальное считаем по людям, а не по Метрике.

Полный расчёт по правилу остановки — **6 октября**, в
`tools/direct-otoplenie.md`.
