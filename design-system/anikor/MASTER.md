# Дизайн-система — студия йоги «Аникор»

Источник: `ui-ux-pro-max --design-system` (стиль Minimalism/Swiss, пара шрифтов
Lora + Raleway для wellness), палитра адаптирована под реальные фотографии
студии: мховые стены, светлое дерево, тёплый и зелёный свет.

## Палитра

| Роль | Светлая | Тёмная | Переменная |
|---|---|---|---|
| Фон | `#F7F4EE` | `#12160F` | `--bg` |
| Фон секции | `#EFEAE0` | `#171C15` | `--bg-alt` |
| Текст | `#1C271F` | `#EDE9DE` | `--fg` |
| Текст второстепенный | `#5A6459` | `#A5AC9E` | `--muted-fg` |
| Карточка | `#FFFFFF` | `#1B211A` | `--card` |
| Граница | `#DED6C6` | `#2F3730` | `--border` |
| Основной (мох) | `#35513F` | `#93B49B` | `--primary` |
| Акцент (бронза) | `#8F6229` | `#D9A566` | `--accent` |
| Золото (декор) | `#C8A15A` | `#D9B87C` | `--gold` |

Контраст проверен: текст ≥ 4.5:1 к фону в обеих темах, акцент используется
для подписей и цен, «золото» — только декоративно (мандала, логотип на фото).

## Типографика

- Дисплей: **Cormorant Garamond** 600 — логотип «АНИКОР», логотип в шапке.
- Заголовки: **Lora** 500.
- Текст: **Raleway** 300–600, базовый кегль 17px, интерлиньяж 1.65.
- Запасные семейства: Georgia / системный sans — сайт не ломается,
  если Google Fonts недоступен.

## Ритм и радиусы

Шкала отступов 8/16/24/32/48/64/96px (`--space-1…7`), «просторная» плотность.
Радиусы: 8 / 14 / 22px и pill для кнопок. Контейнер — 1180px.

## Движение

- Логотип: побуквенное появление (opacity + translateY + blur), задержка 115ms
  на букву.
- Мандала: три кольца вращаются с разной скоростью (90/60/40s), центральное
  кольцо «дышит» 10s, фото — медленный Ken Burns 24s.
- Появление блоков при скролле — IntersectionObserver, 600ms.
- Всё выключается при `prefers-reduced-motion: reduce`.

## Компоненты

Кнопка (pill, min-height 50px), карточка практики, прайс-строка, вкладки
расписания (`role="tablist"` + стрелки), аккордеон FAQ на `<details>`,
форма с инлайн-валидацией, плавающая кнопка WhatsApp.

## Чего избегаем

- эмодзи вместо иконок (используется собственный SVG-спрайт);
- текст поверх фото без затемняющей вуали;
- анимация ширины/высоты — только transform и opacity.
